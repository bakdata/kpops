# Streams Bootstrap

Subclass of [*HelmApp*](<https://bakdata.github.io/kpops/dev/user/core-concepts/components/helm-app/index.md>) and *KafkaApp*.

### Usage

- Defines a [streams-bootstrap](<https://github.com/bakdata/streams-bootstrap>) component

- Often used in `defaults.yaml`

### Operations

#### deploy

Deploy using Helm.

#### destroy

Uninstall Helm release.

#### reset

Do nothing.

#### clean

Do nothing.
